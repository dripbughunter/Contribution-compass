# Changelog

All notable changes to this project are documented in this file.

## [2.0.0] - 2026-09-24

### Added

- Versioned local-storage data format with legacy migration.
- Input validation, safe issue-link protocol handling, and accessible form errors.
- Search, status/priority filters, and multiple sort orders.
- Direct status updates, edit mode, delete undo, and updated timestamps.
- JSON export and import support.
- Automated Node unit tests for the core data layer.
- Contribution guidance, architecture notes, CI workflow, bug-report template, and MIT license.

### Changed

- Split pure state/data logic into `core.js`.
- Improved responsive layout, keyboard focus behavior, and feedback messages.
